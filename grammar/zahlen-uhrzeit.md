## Números
- **13–19: unidad + `zehn`, SIN `und`** → dreizehn, vierzehn, fünfzehn, **sechzehn** *(no sechszehn)*, **siebzehn** *(no siebenzehn)*, achtzehn, neunzehn.
- **21–99: unidad + `und` + decena, TODO JUNTO** → 21 = **einundzwanzig**, 34 = **vierunddreißig**, 87 = **siebenundachtzig**.
- Irregulares en la escritura: **sechzehn**, **siebzehn**, **dreißig** *(no dreizig)*, **sechzig** *(no sechszig)*, **siebzig** *(no siebenzig)*.
- 100 = **hundert** · 1000 = **tausend** · 0 = **null**.
- Dificultad de **oído**: el orden invertido hace que el dato decisivo llegue al final.

## La hora — dos sistemas
**Oficial (24 h):** `[hora] Uhr [minutos]` → 14:30 = *vierzehn Uhr dreißig* · 20:45 = *zwanzig Uhr fünfundvierzig*.

**Coloquial (12 h):**
| reloj | alemán |
|---|---|
| 8:00 | acht Uhr |
| 8:10 | zehn **nach** acht |
| 8:15 | **Viertel nach** acht |
| 8:30 | **halb neun** ⚠️ |
| 8:45 | **Viertel vor** neun |
| 8:50 | zehn **vor** neun |

## 🚨 La trampa `halb`
**`halb acht` = 7:30.** El alemán cuenta **hacia la hora siguiente**; el español, hacia atrás.
🎒 **Con `halb`, súmale uno a la hora española:** "las 7 y media" → *halb **acht***.

## Preguntar
- **Wie spät ist es?** / **Wie viel Uhr ist es?** → *Es ist …*
- **Um wie viel Uhr …?** / **Wann …?** → *Um …*
- Contraste: ***Es ist** acht Uhr* (son las 8) vs ***um** acht Uhr* (a las 8).

## Fórmulas de tiempo (chunks)
| bloque | con | ejemplo |
|---|---|---|
| **um** | la hora | um 8 Uhr |
| **am** | días / partes del día | am Montag, am Wochenende, am Abend |
| **im** | meses / estaciones | im Mai, im Sommer |
| **von … bis** | intervalo | von 9 bis 17 Uhr |
| **ab** | a partir de | ab 8 Uhr |
| *(nada)* | morgen / heute / gestern | Ich fahre morgen. |

## Trampas para hispanohablante
- **halb** (la principal): *halb acht* ≠ "las ocho y media".
- **Orden invertido** de los números (einundzwanzig).
- ***Es ist*** vs ***um***: "son las 8" vs "a las 8".
- **morgen** (mañana=tomorrow) vs **der Morgen** (la mañana) → *heute Morgen* = esta mañana; *morgen früh* = mañana por la mañana (**nunca** *morgen Morgen*).
- Con la hora al inicio de la frase, **no olvides el V2**: *Um 8 Uhr **fährt** der Zug ab.*
