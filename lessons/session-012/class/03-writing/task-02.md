# Tarea 02 (escritura) — mensaje: «llegué tarde, perdón»

> **Registro: mensaje / chat.** **Schreib eine kurze Nachricht** *(escribe un mensaje corto)* de **5–7 frases** a tu amigo **Max**.

## La situación
Habías quedado con Max a las 18:00 y **llegaste tarde**. Escríbele explicando **qué pasó** (en pasado), disculpándote y proponiendo algo.

## Debes incluir (al menos)
- **4+ verbos en Perfekt** contando qué pasó: *der Zug **hat** Verspätung **gehabt*** · *ich **habe** gewartet* · *ich **bin** zu spät **gekommen*** · *ich **habe** den Bus **genommen***
- Una **disculpa**: *Es tut mir leid* / *Entschuldigung!* *(fórmulas fijas)*
- Una **pregunta en Perfekt** dirigida a él: *Hast du …? / Bist du …?*
- Un **imperativo** o una **propuesta con modal** (repaso): *Ruf mich an!* / *Wir können morgen …*
- Una **negación** (*nicht* / *kein-*)

## Frases hechas útiles (A2 — tal cual)
- **Es tut mir leid** (lo siento) · **Entschuldigung!** · **zu spät** (demasiado tarde)
- **um 18 Uhr** (a las 18:00) · **am Bahnhof** · **eine halbe Stunde** (media hora)
- Para **proponer algo** (modelo completo, solo cámbialo): **Wir können morgen einen Kaffee trinken.** / **Wir können morgen um 18 Uhr am Bahnhof sein.**

## Consejos
- Empieza *Hallo Max!* y cierra *Bis bald! / Tschüss!*
- **Experimenta**: si te sale intentar algo nuevo (una frase con *weil*, un relativo…), inténtalo — se premia.
